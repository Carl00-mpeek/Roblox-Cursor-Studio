RBX Cursor Studio

The free Roblox cursor changer for Windows. Make your Roblox cursor yours — custom packs, animated cursors, a built-in editor and instant pack switching.

⬇ Download for Windows View on GitHub Join Discord

Features

Custom Roblox cursors

Replace the arrow, click (hand), text (I-beam) and Shift Lock cursors with any PNG, JPG, CUR or ICO image. Auto-fit and centered on Roblox's own canvas.

Animated cursors (.ANI)

Assign an animated .ani cursor per state with size, speed and FPS controls. Toggle it on or off with a hotkey.

Cursor packs

Save, share and import cursor packs as .rbxcursor files. Switch packs instantly with Ctrl+Alt+1/2/3, even in game.

Survives Roblox updates

Automatic repair reinstalls your custom cursor after every Roblox update. Restore the originals in one click.

Built-in editor

Resize, reposition, colorize, add outline or shadow, and generate color variations without leaving the app.

Effects

Optional cursor trails (stars, fire, smoke, hearts, rainbow), click sounds and Discord Rich Presence.

How to change your Roblox cursor

  1. Download RBX Cursor Studio from the Releases page (Setup or Portable).
  2. Open Roblox once so its cursor folder exists, then start RBX Cursor Studio.
  3. Click Choose on a cursor, pick an image and press Save — it is applied to Roblox instantly.
  4. Save your cursors as a pack to switch between styles any time.

Türkçe — Roblox imleç değiştirme

RBX Cursor Studio, Roblox imlecini (fare imleci) değiştirmek ve özelleştirmek için ücretsiz bir Windows uygulamasıdır. Kendi imleç paketlerini oluştur, animasyonlu .ANI imleçler kullan, imleçleri renklendir ve Ctrl+Alt+1/2/3 kısayollarıyla oyun içinde bile anında paket değiştir. Roblox güncellendiğinde imleçlerin otomatik olarak geri yüklenir. Hemen indir.

Is it safe?

RBX Cursor Studio does not read Roblox's memory or inject code. It only replaces cursor image files in your local Roblox folder and, for animated cursors, draws a separate overlay with standard Windows APIs.
